# GENKI 小規模デイサービス向け送迎配車ソフト — 参考コード

## 【重要：実運用非推奨】

このリポジトリは、小規模デイサービス向け送迎配車ソフトの開発過程を公開する参考資料です。

現在の公開コードには、以下の既知の問題があります。

- NG担当者・NG乗客の制約が配車計算に反映されない
- 一部の計算で迎え時間の制約が守られない
- 欠席等の変更後に古い配車結果が残る場合がある
- 住所変更時に古い緯度経度を使用する場合がある
- 履歴が重複保存される場合がある

**このため、実際の介護送迎業務には使用しないでください。職員による最終確認を前提としても、現状のコードを実運用向けに案内していません。**

本リポジトリは、学習・研究・コードレビュー・開発協力を目的として公開しています。旧版のコードを保存しており、安全上の不具合を修正した版ではありません。

## プロジェクトの背景

このプロジェクトは、実際に日本のデイサービス送迎現場で働く開発者が、送迎業務の属人化を減らすことを目的として作成しました。

開発・公開主体は **OSFグループ合同会社**です。**GENKIブランドの開発活動の一環**として、開発過程と課題を公開しています。

本格的な配車最適化ソフトとしては未完成ですが、小規模施設の送迎業務改善に関心のあるエンジニアからの改善提案を歓迎しています。

## 現在のコードで確認できる処理と制限

Google SheetsとGoogle Apps Script（GAS）を使用します。関数名やコメントに「AI」「最終完成版」などの表現が残っていますが、機械学習・生成AIによる配車や、最適解の保証を実装したものではありません。

| 処理 | 実装の内容・制限 |
| --- | --- |
| マスタ同期 | 利用者IDを照合し、契約・送迎条件シートへ未登録者を追加します。入力全体の整合性を保証する仕組みではありません。 |
| 当日名簿作成 | 曜日契約から名簿を作ります。再作成時には既存の出欠・臨時変更・メモを上書きします。 |
| 往路・復路の割当と順序計算 | 座標から求めた概算距離と時刻条件を使う逐次的な割当です。道路経路・渋滞を考慮した最適経路計算ではありません。NG条件は反映されず、時刻条件も必ず守られるわけではありません。 |
| 定員等の判定 | 一般席・車椅子席の人数を判定する処理があります。介助条件全体や担当職員の適合性を保証しません。 |
| 所要時間の概算 | 緯度経度の差を距離に換算し、概算距離1kmあたり2分と各移動の3分を加算します。実道路の所要時間ではありません。 |
| 住所から座標を取得 | GASのMapsジオコーディングを呼び出します。既存の座標が埋まっていると住所変更後も再取得されない場合があります。 |
| 地図リンク・共有用文章 | 住所のGoogle Maps検索リンクと、手動コピー用の文章を生成します。道路ルートの計算やLINEへの自動送信は行いません。文章の日時・時間欄も実運用に使える品質を保証しません。 |
| 配車結果と履歴 | 結果をシートへ書き込み、保存関数で履歴に追記します。実際の乗降・運行完了を記録する機能ではなく、重複保存防止もありません。 |

作業時間の削減率や、離職防止・加算取得等の効果を裏付ける検証結果は提示していません。対応人数・安全性・性能の実運用保証はありません。

## コードを読むためのシート構成

以下はデータ構造を理解するための情報です。実運用向けの導入手順ではありません。

| シート名 | コード上の役割 |
| --- | --- |
| `m_user_basics` | 利用者ID・氏名・住所・座標 |
| `t_user_contracts` | 曜日契約 |
| `t_user_pickup_conditions` | 時間・車椅子・NG等の入力欄（入力と計算への反映は別です） |
| `m_vehicles` | 車両・定員・便の設定 |
| `m_drivers` | 職員情報（現行の配車計算では使用していません） |
| `t_daily_attendance` | 当日の名簿・出欠・日付・施設座標・共有用文章 |
| `t_routing_outputs` | 計算結果 |
| `t_past_records` | 計算結果の追記先（運行実績ではありません） |

旧配布テンプレートへの直接リンクと、実運用への導入を促す案内・旧デモ動画へのリンクは撤去しました。元のスプレッドシートは削除していません。

検証する場合は、本番とは独立した非公開の環境と架空データだけを使用してください。実在する利用者・職員の氏名、住所、介助情報等を入力しないでください。GitHubのIssue・Pull Requestにも個人情報や認証情報を含めないでください。

## 権限・外部通信・安全性

- 住所から座標を取得する処理はGoogleのMapsサービスに住所を送ります。地図リンクを開いた場合も住所がGoogleへ渡ります。
- 確認した公開コードには、独自のAPIキー、生成AI API、LINE送信API、追加の有料Cloudサービスを使う処理はありません。Google側の利用条件・制限やアカウント設定まで保証するものではありません。
- 公開リポジトリにはGASの権限設定ファイルがなく、旧テンプレートの実際のOAuth同意画面・要求権限・案内リンクは未確認です。安全確認済みとは扱わないでください。不明な権限や不適切なリンクがある場合は認証を進めないでください。
- 排他制御、重複防止、途中失敗からの確実な復旧は実装されていません。
- 詳しくは [SECURITY.md](SECURITY.md) を参照してください。
